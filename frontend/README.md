# TRPZ Frontend

Фронтенд частина додатку для пошуку можливостей.

## Встановлення

```bash
npm install
```

## Запуск

```bash
npm start
```

## Структура

- `/src/pages` - сторінки додатку
- `/src/components` - компоненти
- `/src/services` - API сервіси
- `/src/context` - React контексти

## Функціональність

- Реєстрація та авторизація користувачів
- Перегляд та фільтрація можливостей
- Управління профілем користувача
- Завантаження аватарів
