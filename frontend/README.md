# TRPZ Frontend (HTML/CSS/JS)

Фронтенд частина додатку для пошуку можливостей на чистому HTML, CSS та JavaScript.

## Структура

```
frontend/
├── index.html          # Головна сторінка
├── css/
│   └── style.css      # Стилі
├── js/
│   ├── api.js         # API клієнт
│   ├── auth.js        # Аутентифікація
│   └── app.js         # Головна логіка
└── README.md
```

## Запуск

Відкрийте `index.html` у браузері або запустіть локальний сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js (якщо встановлено http-server)
npx http-server

# PHP
php -S localhost:8000
```

## Функціональність

- ✅ Реєстрація та авторизація
- ✅ Управління профілем
- ✅ Перегляд можливостей
- ✅ Фільтрація за типом, регіоном, тегами
- ✅ Завантаження аватарів
- ✅ Адаптивний дизайн

## API

Додаток працює з бекенд API на `http://localhost:3001`:
- `/auth/*` - аутентифікація
- `/opportunities/*` - можливості
